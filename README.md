# Alexandra Hvile – portefølje

Personlig porteføljeside bygd med HTML og CSS, publisert med GitHub Pages.

- `index.html` – forsiden
- `aspire/index.html` – case: Aspire (IN1060, våren 2026)
- `aspire/kode/` – Arduino-koden for soppen og husenheten
- `stil.css` – all styling
- `bilder/` – bilder fra prosjektene

## Legge siden ut på GitHub Pages

1. Lag en konto på github.com hvis du ikke har det.
2. Lag et nytt, offentlig repository som heter `brukernavn.github.io`, der `brukernavn` er GitHub-brukernavnet ditt.
3. Last opp alt innholdet i denne mappen (ikke selve mappen) med «Add file» → «Upload files», og trykk «Commit changes».
4. Etter et par minutter ligger siden på `https://brukernavn.github.io`.

Endrer du noe senere, laster du opp de endrede filene på samme måte.
